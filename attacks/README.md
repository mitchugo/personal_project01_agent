# attacks/

Attack cases against this lab only. None exist yet.

Each attack case (planned format) should state:

- **ID** and the threat it exercises (e.g. `T-03` in `docs/threat-model.md`)
- **Actor and starting privileges** (which tenant, which role)
- **Input** (prompt, poisoned KB document, crafted ticket, etc.)
- **Expected secure behaviour**
- **Observed behaviour** and a link to the run in `evidence/runs/`

Scope: this local application and its synthetic data only. Do not target third-party
services or model providers.
